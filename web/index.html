Read the experiment honestly.

The controller enumerates feasible partitions using observed reuse. It can lag behind phase changes, and a split that reduces total misses may hurt one tenant. Profiling and reallocation costs are not included in a CPU timing model.

JSON includes the exact seed, all four policies, quotas, miss counts and decision-time evidence.
