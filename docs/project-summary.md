# Project summary

CacheHarbor is a reproducible systems experiment about sharing a small cache between two synthetic programs. It includes a bounded LRU simulator, causal reuse monitors, parameter selection on separate data, four-policy comparisons, an interactive isometric replay, figures from actual results, and automated tests.

Truthful portfolio bullet: “Directed a Codex-assisted cache-partitioning study comparing four policies across held-out synthetic workloads, with reproducible evaluation and an interactive allocation replay.” This does not imply the user independently implemented the code or tested physical silicon.

Visual reference: [TheRollerBlader/motion-graphic-style-library](https://github.com/TheRollerBlader/motion-graphic-style-library), Isometric Studio. Consulted local `catalog/isometric.md`; used clay/sage blocks with three faces, warm paper, locked camera, 0.5-second ease-out entrances and a reduced-motion override. No media or source code from that repository is bundled. Scientific figures use consistent colors but static scientific plotting conventions.
